# AGENTS.md

Tradewind Forever is a WoW: Forever addon (Interface 16001): one crafting profit list across this account's characters, counting only what each can make from its own bags and bank, priced through Auctionator or TSM when installed and vendor prices otherwise. It requires ForeverCore. It lists and explains; it never crafts, buys or posts.

## Standards

- `wow-forever-addon`: https://github.com/cjber/forever-core/tree/main/.agents/skills/wow-forever-addon (the WFA-*
  requirements every WoW: Forever addon meets: UI look, assets, README and store page, CI and release)
- `repo-standards`: the RS-* requirements every cjber and agent-labs-dev repo meets; its `audit.py` checks this repo.
