# Tradewind Forever

A crafting profit list for WoW: Forever across all your characters: what each alt can craft now from its own bags and bank, ranked by profit after the auction cut, and what to buy to craft the best rows again.

It needs [ForeverCore](https://www.curseforge.com/wow/addons/forevercore).

This repository is being set up; the addon lands in the first pull request.
